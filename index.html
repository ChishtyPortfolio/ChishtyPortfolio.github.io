I'm a second-year Computer Science undergraduate at Mawlana Bhashani Science and Technology University (MBSTU), based in Sirajganj, Bangladesh.

My focus areas are Machine Learning and embedded robotics — I like building things that sense the physical world and make decisions, from autonomous line-following robots to computer-vision-based traffic control systems.

I'm self-taught in Python since childhood, and I genuinely enjoy the math underneath it all — calculus and linear algebra especially. Right now I'm working through a structured ML roadmap covering classical ML, deep learning, and PyTorch, with an eye toward Kaggle and a solid GitHub portfolio.

Outside coursework, I work on hardware-software group projects — wiring sensors, tuning control loops, and writing up the results.

Line-Following Robot

Built

An Arduino-based autonomous robot using an 8-sensor IR array and PID control to track a path, built with a 6-member team.

Firmware was extended with zigzag classification via position history, gap handling, and backtracking logic. The team is currently writing a paper on the system, with the PID algorithm and 8-sensor array framed as the key contribution.

AI-Based Intelligent Traffic Management

Built

A computer-vision traffic control prototype for the Microprocessor and Embedded System course, using YOLOv8 detection to drive real signal timing.

A physical 3-lane road prototype with 9 LEDs is controlled by an ESP8266. YOLOv8 detects vehicle density and adjusts signal timers automatically. Lane-change violations trigger an automatic fine and email notification, and emergency vehicles carry a unique ID for priority green time via a connected database.
